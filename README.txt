MY GYM PLAN PREMIUM V4.2

Five improvements added
1. Previous-workout comparison for every exercise, including the exact completed sets from last time.
2. Current and longest training streak on the Home dashboard.
3. Workout-complete summary with duration, sets, exercises, volume and new PR detection.
4. Weekly training-volume trend and a 35-day workout consistency heatmap.
5. Premium Home dashboard with today's workout, this-month count, current weight, top PR and recent volume.

Also preserved from V4
- Compact bottom rest timer with +30s and Skip.
- Timer stops when finishing or signing out.
- Sticky workout header and non-overlapping Finish CTA.
- Existing routines, history, weights, Supabase login and cloud sync.

Install
- Replace index.html, manifest.webmanifest, sw.js, icon-192.png and icon-512.png in GitHub.
- Keep your existing Supabase project and data. No schema change is required.
- Open the deployed URL with ?v=42 once. If the installed Home Screen app stays old, remove it and add it again.
